# Password Reset Guide

## Self-Service
- Customers can reset their passwords using the "Forgot Password" link on the login page.
- An email with a secure link will be sent to their registered email address.

## Support Agent Process
- If a customer contacts support for a password reset, the agent can trigger a reset link to their email autonomously.
- The agent must verify the customer's email address matches the account.
- If the customer lost access to their email, escalate to human support for manual verification.

## Limitations
- Agents cannot view or set a password manually. They can only trigger the reset link.
